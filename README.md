# Curious Minds Study Buddy

Help me make a study buddy that can teach you on Mathematics, Science and Computer Science. This should be able to explain difficult concepts in simple language. It should be able to generate mcq quizzes about the material and provide good but to obvious hints for the questions. It can track the quiz scores and provide good feedback about the areas to develop by evaluating the answers given by students. This should be a python code for a front end and back end. Make the UI consist of a basic grey-white-black colour scheme and buttons to generate quizzes, input information about subject and grade and topic, and a button to get feedback and to know things ti develop on. The topics and subjects will be from grade 8 - 10 so in the button to input information include a 3 choice between 8 9 and 10, and for the quizzes make an option between easy medium and hard and for the subject a choice between science math and computer science.
